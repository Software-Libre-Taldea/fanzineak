# Fanzineak
## Letra tipoak
Erabiltzen ditugun letra tipoak `fonts` karpetan sartu behar dira, editatzen duenak eskuragarri izateko bere ordenagailuan.

## Nola kontribuitu
Lehenik eta behin, `git pull` egin, scribusen konfliktoak buruhauste bat dira bestela.

Fanzine bakoitzak bere karpeta propioa du. Barruan, `Xfanzinea.sla` artxiboa da scribuseko artxiboa. Irudiak eta testuak karpeta egokietan gorde.

```
fanzineX
|
+-- Xfanzinea.sla
+-- irudiak
|   +-- irudia1.png
|   +-- irudia2.webp
|   +-- irudia3.jpg
+-- testuak
    +-- testua1.md
    +-- testua2.odt
    +-- testua3.txt
```

### Testuak eta irudiak kontribuitzeko
- **Testu bat** idatzi baduzu, sartu zure .txt .md edo .odt artxiboa testuak karpetan. 

- **Irudiak** kontribuitzeko, irudiak karpetan sartu.
### Fanzinea montatzeko
**Gomendioa:** Fanzinea pertsona bakarrak montatzea gomendatzen da, scribuseko konflikto gutxiago egoteko. Zertan ari zaren badakizu, egin aurrera, lasai.

**Garrantzitsua:** Scribusen bertsio desberdinek arazoak eman ditzakete, erabili beti bertsio bera dokumentu bat editatzeko. Orain, scribus 1.6.1 erabiltzen dugu.

Fanzinea montatzeko, scribus instalatuta eduki behar duzu, eta `.sla` artxiboa editatu.
